# 팀 진행 내용

## 1. 기획 회의

다양한 의견이 오갔습니다. 최종 후보군에 올라온 것은 **기준치를 만족하면 자동으로 환전을 해주는 서비스**와 **중고거래에서 경매가 가능한 플랫폼 서비스**였습니다. 이 중 팀 내에서 더 많은 득표를 얻은 첫 번째 의견을 확장하고 구체화하여 **해외 여행을 위한 모임 통장 및 지출 정리가 가능한 서비스**를 기획하였습니다. 이는 기존에 제공하는 서비스 중 **트래블월렛, 트래블로그**와 유사합니다. 

## 2. 프론트엔드 와이어프레임 작성

기획한 내용을 바탕으로 Figma를 활용하여 와이어프레임을 작성하였습니다. **홈, 환율, QR코드 결제, 박스 사용 이력, 더보기** 다섯 개의 바텀 내비게이션 메뉴로 이뤄져 있습니다. 홈 탭에서는 자신이 가진 한화 및 외화의 페이머니, 자신이 속한 박스(모임 통장과 유사한 저희의 서비스입니다)를 확인할 수 있습니다. 환율 탭에서는 여러 국가의 환율을 조회할 수 있고 자동 환전을 위한 기준을 설정할 수 있습니다. 박스 사용 이력에서는 해당 박스에서 지출된 통계를 조회할 수 있습니다. 이 틀을 바탕으로 필요한 기능의 와이어프레임을 작성하였습니다.

## 3. 백엔드 요구사항 명세 및 ERD 작성

기획한 내용 및 프론트엔드 와이어프레임을 활용하여 기능을 구체적으로 명세하고 관련 ERD를 설계하였습니다. 서비스와 관련된 핵심 요구사항들로는 **페이머니 충전 및 환불, 모여박스로 페이머니 이체 및 인출, 환율 정보 조회 및 환전, QR코드를 활용한 결제 및 가맹점 관리, 페이머니 지출 이력 조회** 등이 있습니다.

# 기여 내용

## 1. 프론트엔드 와이어프레임 작성

**환율** 탭에 해당하는 부분을 맡아 **Figma를 작성**하였습니다. 구체적으로는 환율 탭의 첫 화면에서 여러 국가의 환율이 보이고, 어떤 국가의 환율을 클릭하면 환전 화면으로 이동할 수 있으며, 환율이 어떻게 변화했는지 그래프 볼 수 있게 하였습니다. 또 특정 국가의 환율을 검색하기 위한 바텀 시트, 예약 환전을 위한 플로우 및 화면을 작성하였습니다.

## 2. 프론트엔드 안드로이드 프로젝트 구조 설계 및 작성

현대적 안드로이드 개발 방식을 배우는 동시에 다른 프론트엔드 팀원과 협업하기 위해서 프로젝트를 구조화하고 각 패키지에는 어떤 내용이 들어가야하는지 문서화하였습니다. 또한 간단한 뼈대 코드를 완성하여 화면 역할을 분담하기 편하게 해뒀습니다.

```jsx
com.d108.moyeo
├── data                // 데이터 계층: 데이터 소스 및 구현체 관리
│   ├── local           //  - 로컬 데이터 (Room DB, DataStore)
│   ├── mapper          // 서버와 로컬 데이터 양식을 변환하는 도구  
│   ├── remote          //  - 원격 데이터 (Retrofit API)
│   │   ├── api         // 기능별 하위 패키지 추가 가능
│   │   └── dto         // 기능별 하위 패키지 추가 가능
│   └── repository      //  - Domain Repository 인터페이스의 '구현체'
│       └── UserRepositoryImpl.kt
│
├── domain              // 도메인 계층: 앱의 핵심 비즈니스 로직 (순수 Kotlin)
│   ├── model           //  - 앱의 핵심 데이터 모델 (ex: User.kt)
│   ├── repository      //  - 데이터 계층의 '설계도' (인터페이스)
│   └── usecase         //  - 개별 기능 단위의 비즈니스 로직. 기능별 하위 패키지 추가 가능
│
├── presentation        // 프레젠테이션 계층: UI와 상태 관리 (Android Framework)
│   ├── navigation             //  - Jetpack Compose Navigation 그래프 및 라우트 정의
│   │   ├── AppNavGraph.kt
│   │   └── Screen.kt
│   ├── theme           //  - Compose UI 테마 (Color, Typography, Shape)
│   │   ├── Color.kt  // 색상
│		│		├── Dimens.kt  // 간격, 패딩
│   │   ├── Theme.kt
│   │   └── Type.kt  // 폰트
│   └── ui              //  - 실제 UI 화면 및 구성 요소
│       ├── component   //      - 앱 전역에서 재사용되는 UI 부품 (ex: CommonButton.kt)
│       └── screen      //      - 기능별 화면 단위의 Composable 및 ViewModel // 기능별 하위 패키지 추가 가능
│           ├── home
│           │   ├── HomeScreen.kt
│           │   └── HomeViewModel.kt
│           └── login
│               ├── LoginScreen.kt
│               └── LoginViewModel.kt
│
├── di                  // 의존성 주입 계층: Hilt 모듈
│   ├── AppModule.kt
│   ├── NetworkModule.kt
│   └── RepositoryModule.kt
│
├── util                // 유틸리티: 앱 전반에서 사용되는 공통 코드
│
└── MyApplication.kt     // 앱 시작점 및 Hilt 초기화
```
